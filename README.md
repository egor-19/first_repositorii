Vector - динамический массив на Python
Описание проекта
Vector — это реализация динамического массива (аналог list в Python) с использованием низкоуровневых ctypes-массивов. Проект создан в образовательных целях для глубокого понимания работы динамических структур данных и магических методов Python.

Возможности
Основные операции:

append(element) — добавление элемента в конец

pop(index=-1) — удаление и возврат элемента по индексу

insert(index, value) — вставка элемента по индексу

remove(value) — удаление первого вхождения значения

clear() — полная очистка вектора

Доступ к элементам:

getitem(index) — получение элемента по индексу (поддерживаются срезы)

setitem(index, value) — изменение элемента по индексу

delitem(index) — удаление через del

Информация о векторе:

len() — получение длины

contains(value) — проверка наличия элемента (in)

index(value) — поиск индекса первого вхождения

count(value) — подсчёт количества вхождений

Итерация и представление:

iter() — поддержка цикла for

reversed() — обратная итерация (reversed())

str() — строковое представление для пользователя

repr() — представление для отладки

Операторы:

add() — конкатенация векторов (v1 + v2)

iadd() — конкатенация с присваиванием (v1 += v2)

mul() — повторение вектора (v * n)

eq() — сравнение (==)

ne() — неравенство (!=)

Преобразования:

copy() — создание копии вектора

extend(other) — добавление элементов из другого вектора или списка

reverse() — переворот порядка элементов на месте

sort() — сортировка пузырьком

Управление памятью:

Автоматическое расширение массива в 2 раза при заполнении

Начальная ёмкость — 10 элементов

Внутреннее использование ctypes.c_int для низкоуровневой работы
